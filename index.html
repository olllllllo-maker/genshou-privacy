プライバシーポリシー

最終更新日: 2026年10月10日

1. 本ツールについて

本ツールは、個人が運営するYouTubeチャンネル「現象教訓」に、自作のショート動画を自動投稿するためのツールです。YouTube Data API v3 を使用しています。

2. 収集する情報

本ツールが取得・保存する情報は、YouTubeアカウントの認証情報（OAuthトークン）のみです。この情報は、運営者自身のチャンネルに動画を投稿する目的でのみ使用し、運営者のローカル環境に保存されます。

3. 情報の利用目的

取得した情報は、動画の投稿処理以外の目的には使用しません。

4. 第三者への提供

取得した情報を第三者と共有、販売、または開示することはありません。

5. YouTube API サービスについて

本ツールは YouTube API サービスを使用しています。利用にあたっては YouTube利用規約 および Googleプライバシーポリシー が適用されます。Googleアカウントの設定ページ（https://security.google.com/settings/security/permissions）から、いつでも本ツールへのアクセス権を取り消せます。
